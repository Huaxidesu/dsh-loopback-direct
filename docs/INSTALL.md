# 回环直连安装与更新

回环直连（`dsh-loopback-direct`）是 DeepSeek Harness（DSH）的插件。它让 WorkBuddy 等本机模型在开启网络代理时仍通过回环地址直连。打开 **设置 → 回环直连** 可以查看并验证 billion-context 转发器的补丁状态。

## 从 ZIP 离线安装

1. 把离线 ZIP 复制到目标机器并解压。解压目录包含本说明、线上安装地址和 `dsh-loopback-direct-<版本>.tgz`。
2. 打开 DSH 的 **插件**，点 **添加插件**。填入解压目录中 `.tgz` 文件的绝对路径，按 DSH 的提示确认。也可以把同一个绝对路径交给 Agent，让它通过 DSH 插件管理器安装。
3. 确认插件列表中出现并启用了「回环直连」。如果 DSH 提示重启，退出并重新打开 DSH。
4. 打开 **设置 → 回环直连**。如果显示未打补丁且可打补丁，点 **打补丁**。如果显示待重启，退出并重新打开 DSH。启动本机模型后点 **验证**，再发送一条聊天消息检查回复。

离线包包含回环直连本身。目标机器要先安装 DSH、启用 billion-context，并配置好 WorkBuddy 等本机模型。已核对的环境是 DSH Desktop 2.0.24-next 和 billion-context 0.1.216。

## 通过 GitHub Release 在线更新

希望在 DSH 里直接更新时，首次安装请在 **插件 → 添加插件** 填写 ZIP 内 `在线安装地址.txt` 里的 Git 地址，或复制对应 GitHub Release 说明里的 Git 地址。该地址固定到某一份正式发布的提交。

打开 **插件 → 回环直连更新** 检查 GitHub 最新正式版。也可以点 **重新检查**。如果有新版本，Git 安装的副本会显示 **更新…**。核对 DSH 确认窗口里的目标版本并确认，等安装完成后按提示重启。重新打开更新页即可核对版本。遇到 GitHub API 限流时，插件会尝试从公开发布页和 Git 标签查询版本。

更新窗口停在「正在更新」不动时，安装通常已经在磁盘完成：点窗口的 **关闭**，再点插件页的 **刷新** 或重开 **回环直连更新**，「已安装版本」会显示新版本号。新版本要真正跑起来还得重启 DSH：插件代码换了磁盘内容，当前进程仍执行旧代码，更新页在重启后才会用新逻辑检查版本。

如果当前是目录、`.tgz` 或其他来源安装，可以在更新页查看新版本。需要切换到在线更新时，先在 DSH 插件管理器移除旧的「回环直连」包，再用上面的 Git 地址安装。想继续离线更新时，移除旧包后安装新 ZIP 中的 `.tgz`。完成后在 **设置 → 回环直连** 重查补丁状态。

## billion-context 更新后

billion-context 自己的升级可能替换转发器文件。更新完成后打开 **设置 → 回环直连**。升级监护会在此时检查安装，如果还能识别补丁位置，就会补回分流规则。补丁写入后出现重启提示时，重启 DSH 再验证。找不到唯一补丁位置时，需要等待回环直连适配新版本。

正式版与离线包下载见 [GitHub Releases](https://github.com/Huaxidesu/dsh-loopback-direct/releases)。
